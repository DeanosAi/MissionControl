# Journal - Friday, 4 April 2026

## Content Hub - Mac build and GitHub release

### Summary
Content Hub is now cross-platform with downloadable installers for macOS and Windows, hosted on GitHub with automated CI/CD builds.

### What was done

**GitHub setup**
- Pushed the full Content Hub codebase to GitHub: [DeanosAi/Content-hub](https://github.com/DeanosAi/Content-hub)
- Created three commits covering the initial codebase, workflow improvements, and cleanup
- `.gitignore` covers `node_modules`, `dist`, the Rust target directory, `.db` files, and build logs

**GitHub Actions CI/CD**
- Workflow: `.github/workflows/build-mac.yml`
- Matrix strategy builds Apple Silicon and Intel in parallel on `macos-latest`
- Triggers automatically on push to `main` or `master`
- Uses `npx tauri build --target <arch>`
- Uploads DMG and `.app` bundle artifacts with 30-day retention

**Build results**
| Platform | File | Size |
| --- | --- | --- |
| macOS Apple Silicon (M1/M2/M3) | Content-Hub_0.1.0_aarch64.dmg | 9.9 MB |

| Windows (MSI) | Content-Hub_0.1.0_x64_en-US.msi | 8.1 MB |
| Windows (Setup) | Content-Hub_0.1.0_x64-setup.exe | 5.6 MB |

**GitHub release**
- Tag: `v0.1.0`
- URL: https://github.com/DeanosAi/Content-hub/releases/tag/v0.1.0
- All four installers uploaded as release assets

### Notes
- macOS builds are unsigned, so users need right-click > Open on first launch to bypass Gatekeeper
- Future code pushes automatically trigger new Mac builds
- Local Windows builds still run via `cargo tauri build` on the dev machine
